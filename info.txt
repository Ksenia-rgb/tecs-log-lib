Если fallback == false:
  Логи не будут уходить в fout_default
  fout_default не откроется, ему только назначится имя.
  Другой файл:
    назначится имя,
    если это имя == default_filename, тогда откроется fout_default
    иначе откроется заданный файл

  chooseFout():
    если заданное имя файла filename_ == default_filename, тогда вернет fout_default,
    во всех остальный случаях - fout_;

  push():
    выбирает файл, возвращает его состояние

Если fallback == true:
  Логи будут уходить в fout_default при ошибке в основном потоке
  fout_default откроется сразу
  Другой файл:
    назначится имя,
    если это имя == default_filename, тогда откроется fout_default (в open есть проверка на повторное открытие файла)
    иначе откроется заданный файл

  chooseFout():
    если заданное имя файла filename_ == default_filename, тогда вернет fout_default,
    если с файлом что-то не так, вернет fout_default,
    иначе - fout_.
